# Dev Sharma Portfolio

Next.js 16 portfolio site with static export support for free hosting.

## Quick Start

```bash
# Clone and setup
npm ci
npm run dev  # Local dev at http://localhost:3000
```

## Deployment Options

### Free GitHub Pages (Recommended)
1. Push to GitHub: `git remote add origin <your-repo-url> && git push -u origin main`
2. Enable Pages in repo Settings → Pages (main branch source)
3. Wait for workflow to deploy (check Actions tab)
4. Visit `https://<username>.github.io/marlo-folio`

### Free Vercel (Alternative)
1. Push to GitHub
2. Import repo to Vercel (vercel.com)
3. Configure `vercel.json` for API routes
4. Automatic deployments on push

## Making Changes & Redeploy

1. Edit any file locally
2. Test with `npm run dev`
3. Commit changes: `git add . && git commit -m "Update portfolio content"`
4. Push to GitHub: `git push origin main`
5. Wait for workflow to redeploy
